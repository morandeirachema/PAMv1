pamv1 Autofill

This extension calls pamv1's own POST /api/credentials/<id>/reveal — the same audited path the portal uses — with a token that can do nothing else. Nothing typed here ever leaves your browser except to the pamv1 server URL below.

Server connection

Mint one from an already-signed-in session: POST /api/extension-token (requires the reveal_secret capability). It is refused on every route but the reveal one above, and expires on its own — see the portal for its lifetime.

Site → credential mapping

The extension has no way to browse your vault — it can only reveal a credential ID you give it. Add one row per site you want autofill on.
